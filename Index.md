# Toolbox

Start here.

Download Obsidian. Clone this repo. Open this folder as a vault. The [[toolchains/hop-80|Hop-80]] toolchain is the proof of unbounded context.

## Install Obsidian

On Omarchy:

```
sudo pacman -S obsidian
```

Open Obsidian. Open folder as vault. Pick this clone.

## Three folders

- [[inbox/README|inbox]] — drafts and packets. Not tools.
- [[tools/Index|tools]] — one note per tool. The note names a script.
- [[toolchains/Index|toolchains]] — tools in a fixed order.

## The kit

[[toolchains/hop-80|Hop-80]]. Three tools:

1. [[tools/inject-foot|inject-foot]] — put text into another foot.
2. [[tools/bare-foot|bare-foot]] — launch an empty foot. The harness is an argument. Default is hermes.
3. [[tools/hop-80|hop-80]] — at 80% full, start a new foot and continue the current work. Do not summarize.

A [[smart-node]] already has [[Omarchy]] and a house agent in a [[harness]]. You bring the model.
