# Omarchy

Omarchy is a configuration layer on Arch Linux.

It ships Arch packages, Hyprland, its own package repository, and the `omarchy-*` commands. That is the system. A hostname is not the system.

This toolbox is for that system. The node already has it. This note does not check it, and it does not install it.

See [[smart-node]] and [[harness]].
