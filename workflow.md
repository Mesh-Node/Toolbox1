# workflow

Confirm, then promote. Do not reverse that.

## 1. Read

[[Omarchy]]. [[smart-node]]. [[harness]]. [[tool]].

## 2. Make one piece

One job. One script in `scripts/`. Same input, same output.

## 3. Confirm

Run it on this host. Write down the input and the output. If you had to explain a missing step out loud, the note is incomplete. Fix the note. Run it again.

## 4. Promote

Only then: put the note in `tools/`, link it from [[tools/Index]], and name the script in the note.

## 5. Stop

Do not promote the next piece in the same pass. Do not add a script whose only job is to announce the operating system.
