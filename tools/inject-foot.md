# inject-foot

Put text into another foot. The foot must already be open. You need its window address.

Script: `scripts/inject-foot`

```
scripts/inject-foot ADDRESS "the sentence"
```

The script focuses that one address, pastes the text, and presses return. It does not spawn a foot. It does not close a window.

Do not paste a password. Do not paste a token.

Pass: the sentence is in that foot, and only that foot.
