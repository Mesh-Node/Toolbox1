# bare-foot

Launch an empty foot. No packet. No old chat. The origin stays.

Script: `scripts/bare-foot`

```
scripts/bare-foot
scripts/bare-foot hermes
```

The first argument is the harness. Default is hermes. Change the argument to swap the harness. The script launches:

```
omarchy launch tui --app-id=org.omarchy.agent HARNESS chat --cli
```

Pass: a new terminal opens and the harness is waiting. No packet was sent.
