# smart-node

A host running an agent. Descriptive. Not a standard.

The public page is [Mesh-Node/mesh-node](https://github.com/Mesh-Node/mesh-node#smart-node).

On that page, a smart node reads a packet and does the work. Files stay on disk. The packet names them.

This toolbox assumes that node already exists. It already has [[Omarchy]]. It already has a house agent in a [[harness]]. This folder is what that agent uses.

See [[tool]] and [[workflow]].
