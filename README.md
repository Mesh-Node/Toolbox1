A toolbox is notes on disk plus lessons. Copy this folder onto a host. The agent runs what is in here. You bring the model.

Local first. GitHub last. Nothing leaves this host until tested here.

## Quick start

Paste this to an agent only after Mesh-Node/mesh-node said Stop.

```

2. Read ONLY BASE.md, then playbooks/INDEX.md. Do not read PLAYBOOK.md. Do not read the rest of this README.
3. Run published base playbooks in order. Scripts are in scripts/.
4. After each playbook append one line to procedure-state.md on this computer. Do not commit that file.
5. When detect-base prints STOP PASS: stop. Report that line. Do not open an unpublished card.

No passwords. You build the tool. You do not copy another home.
```

Seed first. Then this file. The donor board stays on the donor.
