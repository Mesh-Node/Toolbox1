# Toolbox1

This toolbox is for Omarchy.

The new node already has Omarchy. It already has a house agent in a harness. You bring the model. This folder is the toolbox.

Open this folder in Obsidian. Start at Index.md. The first playbook is playbooks/01-ready.md.

```
./scripts/ready
```

Pass is two lines: PASS omarchy and PASS harness. If either fails, stop. Do not install.
