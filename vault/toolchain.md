# Toolchain

A **toolchain** is a note under `toolchains/`.

It is an ordered combination of [[tool]] notes. A wrapper script comes after that order has been run by hand.

The worked example is [[hop-80]]. Detect, then packet-build, then hop-send. The note is the order. Pattern: [[inbox/admit]].

A wrapper waits until the order has been run on Omarchy.

See [[tool]].
