# Omarchy Toolbox

This vault is the operational toolbox for an Omarchy Hermes harness.

A [[tool]] is a note. A [[toolchain]] is an ordered set of those notes. The executable lives in `scripts/`. Write a tool note when the command exists and a human has run it.

## Operating principle

1. Read this vault and the filesystem first.
2. Use the terminal for inspection and for anything the shell can do.
3. Close one Hyprland address. Never a class.
4. Verify, then write a note. A tool note points at a command that exists.

## Scope

- Compaction stays off. The hop line is `int(window * 0.8)`.
- grok-4.7 is 500000 on the xAI card. That line is 400000.
- The hop chain is [[hop-detect]], [[packet-build]], [[hop-send]], [[close-the-foot]].
- Credentials stay on the logged-in host, outside this folder. See `../DENY.txt`.
- Personal notes stay in the personal vault.

## Evidence

- `verified-local` — observed on this host, with date and method.
- `untested` — proposed. Awaiting a run.
- `obsolete` — historical. Revalidate before use.
